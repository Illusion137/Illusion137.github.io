A multilanguage lightweight version of Pokemon Showdown using a combination of:

- C++ - Orchestrating everything and running the game
- Prolog - Validating the Pokemon teams to see if they could actually exist
- Racket - Parsing the Pokemon team files (in showdown format)
- TypeScript - Web scraping Smogon for their Pokemon data.
